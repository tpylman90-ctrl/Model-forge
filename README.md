# Model Forge

**Model Forge** is an open-source, touchscreen-first GLB geometry editor for Android, built with Godot 4 and GDScript.

Development is underway. The first milestone targets: native Android file picking; GLB import/export; selecting a mesh and vertex; moving mesh vertices with numerical or touch controls; undo/redo; a live 3D viewport; and a reference-image panel.

Source is licensed under MIT. Work-in-progress builds are for testing: keep backups of original GLBs, because imported glTF content may not round-trip perfectly.
